# Word contrasts

These are not arbitrary dictionary comparisons such as fish versus goat.

Each note starts from a real communicative intention that came up and compares
Chinese alternatives that could plausibly compete for that same job. The point
is what changes for a listener: referent, register, speech act, implied
relationship, degree of commitment, politeness, or some other part of the
meaning.

The unit may be one word or a longer phrase. Long filenames are acceptable when
the context belongs in the filename.

The flat ordering in `words/` is deliberately provisional. These notes are the
beginning of the context-dependent representation that should eventually replace
a single context-free order.
