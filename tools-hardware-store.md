# Spanish: hardware-store and tool working set

Goal: cover the ordinary tool vocabulary of a well-stocked hardware store,
garage, maintenance shop, construction site, and home workshop.

Dialect policy:

- Prefer **Guatemalan Spanish** when there is a real regional choice.
- Record Venezuelan usage second when it differs usefully.
- Keep widely understood alternatives when coworkers may use them.
- Prefer the word a worker would actually say over an artificially "pure"
  dictionary translation.
- Use Guatemalan/Central American voseo in coworker phrases.

This file complements [`auto-shop.md`](auto-shop.md). Automotive-specific
parts and diagnostic language stay there; general tools live here.

## Terms worth listening for

These are deliberately retained as alternatives because a real shop may use
them even when another term is preferred here:

- `tenazas`, `alicate`, and `pinza` for plier-like tools;
- `perica` for an adjustable wrench or certain adjustable pliers;
- `dado` versus `copa` for a socket;
- `ratchet`, `matraca`, and `trinquete`;
- `taladro` and `barreno`;
- `esmeriladora` and `pulidora`;
- `cuchilla`, `navaja`, and `cutter`;
- `serrucho de punta` for a jab/keyhole/drywall-style hand saw;
- `sierra caladora` for a jigsaw;
- `tablayeso` for drywall.

The point is recognition in both directions: learn the Guatemala-first form,
but do not treat a coworker's alternate Latin American term as wrong.
