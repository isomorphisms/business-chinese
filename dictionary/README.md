# Bidirectional Arabic–English dictionary

This directory is one dictionary. Do not split words and phrases into separate
directories: any expression useful as a translation unit may be an entry.

## Entry format

- The filename is the exact Arabic or English expression.
- The file body contains opposite-language translations, one per line.
- Order is provisional isolated-lookup order: ordinary/useful renderings first,
  rarer or more marked renderings later.
- That order is not a claim that translation is context-free.
- Whole phrases are first-class entries just like single words.
- Transliteration is not a translation line and is not mixed into these files.

## Closure rule

Every expression occurring on a translation line must itself exist as an entry
in this same directory.

Reverse entries are authored independently. If C1 points to E1, the E1 file is
not generated by simply writing C1 back into it. E1 gets its own Arabic
candidates and its own ordering. C1 might be third there, or only appropriate
in a restricted context.

Whenever expansion introduces a new expression, expand that expression in the
other direction too. Continue recursively until no admitted translation is
left without an entry.

This is closure over translations admitted into the working dictionary, not a
claim that every imaginable slang, historical, metaphorical, or domain-specific
translation forms a finite set.

## Arabic target

Prefer Yemeni spoken Arabic when we have a genuinely Yemeni form. Preserve
cross-regional, MSA, Levantine, Iraqi, Lebanese, Syrian, Egyptian, and other
forms rather than silently relabeling them as Yemeni.

The current seed deliberately includes broad Arabic forms while Yemeni ordering
is still being filled in.

## Seed: old-man / sitting component

The first connected component starts from:

    hey old man, take a seat

It intentionally separates respectful or congenial address from descriptive
and potentially marked words for an old man. For example, `يا عم` and
`يا شيخ` are address forms, while `شايب`, `شيخ`, `عجوز`, and
`رجل كبير في السن` occupy overlapping but non-identical territory.

The files themselves remain deliberately minimal. Later register, dialect,
social-effect, and context records can describe edges without changing the
basic closure rule.
