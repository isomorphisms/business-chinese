# Business Chinese

Personal Chinese-learning material and distributable builds.

For now, reusable learner software is developed in
[place-of-honor/learn-toki-pona](https://github.com/place-of-honor/learn-toki-pona).
Do not fork the language-learning engine into this repository yet.

This repository owns:

- Business-Chinese-specific phrases, vocabulary, dialogues, drills, and notes.
- APKs and command-line binaries built for this material.
- Build metadata tying every published artifact to the exact learner source commit.

Factor the reusable learner into its own repository only when it is sufficiently
independent to stand on its own.
