# Words

Each file is an English prompt taken from Chinese material that has actually come up.

Inside a file, put one Chinese candidate per line. For now the lines are forced into
a single order from the most likely default translation in isolation downward.
That order is only a temporary crutch; it is not a claim that translation has a
context-free total order.

`∅` means that using no separate Chinese word is often a viable rendering.

Do not pad this with dictionary curiosities merely because a translation exists
somewhere. Add candidates that are genuinely plausible for something we were
trying to say.
